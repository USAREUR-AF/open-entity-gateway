# goat-transformers, copied

The Python engine of [goat-transformers](https://github.com/USAREUR-AF/goat-transformers) (Apache-2.0, standard library only), with the model modules `core`, `track`, `cat062`, `sapient` and the packs `canonical-track-v2`, `cot-xml`, `asterix-cat062`, `sapient`, copied at the commit in `COMMIT`. `SHA256SUMS` lists every copied file. Never edit these files: change them with `python tools/sync-goat-transformers.py <checkout>` and check them with `--check`. Used by `encoder: goat-transformers` on the CoT, ASTERIX CAT062 and SAPIENT destinations ([docs/goat-transformers-encoder.md](../../../docs/goat-transformers-encoder.md)).
