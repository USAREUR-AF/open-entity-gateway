# Example records

Version 2 records as first-bite publishes them, one per line.

| File | Records | Made by |
|---|---|---|
| `weather-station.records.jsonl` | Heartbeat, two Observation, Position, one unknown type | first-bite's own `examples/weather-station.records.jsonl` at commit `d65b0389`, copied unchanged |
| `harbour-buoy.records.jsonl` | Position, Sea State, Status | first-bite's `rest` sink at commit `ee604524`, from a capture of the harbour-buoy dictionary of [hello-galaxy-first-bite](https://github.com/USAREUR-AF/hello-galaxy-first-bite) at commit `35d447a3` |

Both message sets are synthetic. The addresses in the records are documentation addresses (RFC 5737).
